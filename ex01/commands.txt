===
Название: date
Описание: используется для отображения системной даты и времени
Синтаксис: date [опции] [+format]
Пример: date -u +"%Y-%m-%d %H:%M:%S"
Примечание: можно настроить формат для вывода даты и времени

===
Название: whatis
Описание: показывает краткое описание команды
Синтаксис: whatis [опции] command
Пример: whatis ls
Примечание: помогает быстро ознакомиться с командой без открытия документаци

===
Название: file
Описание: выводит информацию о файле
Синтаксис: file [опции] filename
Пример: file hello.txt
Примечание: команда не только смотрит на метаданные, но и анализирует содержимое

===
Название: zip
Описание: Сжимает в архивы ZIP
Синтаксис: zip [опции] archiv_name files/directories
Пример: zip archive.zip file1.txt file2.txt
Примечание: сжимает как множество файлов так и каталоги. для распаковки используется unzip

===
Название: find
Описание: ищет файлы и каталоги по заданным условиям
Синтаксис: find [начальнный каталог] [опции] [условия] [действия]
Пример: find /home -name "*.txt"
Примечание: позволяет найти файлы и каталоги по имени, размеру и дате

===
Название: df
Описание: показывает информацию о занятом и свободном месте на диске
Синтаксис: df [опции] [каталог]
Пример: df -h
Примечание: с опцией -h вывод становится более читаемым 

===
Название: uptime
Описание: сообщает как долго работает система
Синтаксис: uptime [опции]
Пример: uptime
Примечание: полезна для мониторинга состояния системы

===
Название: useradd
Описание: регистрирует нового пользователя
Синтаксис: useradd [опции] username
Пример: sudo useradd newuser
Примечание: обычно требует права администратора - поэтому с sudo

===
Название: ping
Описание: проверяет доступность узла в сети, измеряет время отклика 
Синтаксис: ping [опции] node_address
Пример: ping google.com
Примечание: полезна для диагностики сети

===
Название: cowsay
Описание: выводит коровку, "говорящую" заданный текст
Синтаксис: cowsay [опции] text
Пример: cowsay -f dragon "hello world"
Примечание: опция -f позволяет выбрать другого животного - от утки до дракона
